# Voiceger (GPT-SoVITS) Zundamon TTS — Python 3.10 requirements.
#
# IMPORTANT — environment isolation:
#   This repo is developed under direnv + Nix, which exports a huge
#   PYTHONPATH pointing at Python 3.13 Nix site-packages (cffi, matplotlib,
#   ...).  If that leaks into a Python 3.10 venv, imports fail with
#   "Version mismatch" cffi/numpy errors.  The launcher
#   (run-voiceger-server.sh) unsets PYTHONPATH and friends before starting
#   the server; mirror that in any ad-hoc invocation.
#
# pyopenjtalk does not have a CPython wheel for 3.10 and builds from source;
# the source build fails under Nix CFLAGS/NLSPATH pollution, so build it with
# a clean environment:
#   env -i PATH=/home/you/.nix-profile/bin:/usr/local/bin:/usr/bin:/bin \
#         HOME=/home/you uv pip install --python <venv>/bin/python pyopenjtalk
#
# jieba_fast's wheel build is broken for cp310; plain jieba provides all the
# `jieba_fast.posseg.lcut` symbols GPT-SoVITS uses.  Create a forwarder at
# <venv>/lib/python3.10/site-packages/jieba_fast/ with __init__.py and
# posseg.py that re-export from `jieba` and `jieba.posseg` (see
# setup-jieba-fast-shim.sh).
#
# Torch: the CUDA 12.1 wheels build up to compute-capability 12.0 (RTX
# 50-series) is not yet shipped; the RTX 5050 (cc 12.0) will therefore fall
# back to CPU.  To run on GPU, install a newer torch with the Blackwell build
# of cu12x once it is released (or use the rocm build); the code paths are
# identical because GPT-SoVITS selects torch.device() at runtime.
#
# torch (via cu121 index):
#   uv pip install --index-url https://download.pytorch.org/whl/cu121 \
#     torch==2.1.2+cu121 torchvision==0.16.2+cu121 torchaudio==2.1.2+cu121
#
